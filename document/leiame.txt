Dev. Front-End: Gabriel Luis, Bruno Pimenta & Arthur Leite
Design Gráfico: André Sette

(4) Objetivo principal

Desenvolver um site catálogo para uma empresa do segmento de tecnologia, aplicando conceitos de desenvolvimento web e proporcionando uma navegação simples, organizada e acessível.

(5) Descrição

O projeto consiste na criação de um site catálogo para a empresa fictícia BH Tech, utilizada como referência para aplicação dos conhecimentos da disciplina. O site conta com páginas de produtos, contato, localização, equipe e funcionalidades interativas desenvolvidas com HTML, CSS e JavaScript.

(6) Finalidade

O projeto possui finalidade acadêmica, sendo desenvolvido para aplicar os conhecimentos adquiridos na disciplina e demonstrar a utilização de tecnologias web na criação de uma plataforma digital.

(7) Participação dos integrantes

Matheus Bach (Tech Lead): Coordenação do projeto e desenvolvimento das principais páginas e componentes.

Gabriel Luis (Front-End): Desenvolvimento e estilização de páginas.

Bruno Pimenta (Front-End): Implementação da interface e organização do conteúdo.

Arthur Leite (Front-End): Desenvolvimento, testes e ajustes visuais.

André Sette (Designer Gráfico): Criação da identidade visual.

Pedro Borges (Copywriter): Produção e revisão dos textos.

(8) Aplicação do projeto

O projeto foi publicado na plataforma Vercel, permitindo seu acesso online.

Link: https://bh-tech-web.vercel.app/index.html

(9) Conclusão

O projeto permitiu aplicar conhecimentos de HTML, CSS e JavaScript, além de desenvolver habilidades de trabalho em equipe e desenvolvimento web. Os objetivos propostos foram alcançados com sucesso.
